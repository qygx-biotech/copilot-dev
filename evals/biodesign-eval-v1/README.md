# BioDesign immutable evaluation v1

This is an **original, entirely synthetic controlled project**. Every paper, author, note, memory, measurement, identifier and outcome is invented for software evaluation. The text fixtures are original UTF-8 source text, **not PDFs or real publications**. A production adapter may render the declared pages to valid PDFs before ingesting them, preserving page numbering and recording byte hashes. No external search can establish the truth of these fixtures.

The frozen suite contains 96 cases: 72 development cases (75%) and 24 heldout cases (25%). The 24 primary EctD cases have 18 development and 6 heldout cases; the 72 CelluWeave cases are explicitly tagged `open_domain_celluweave` and are a novel-domain stress suite, not a substitute for primary application coverage. Paired questions always share a split. Heldout gold and outcomes must not be used to select a change.

`cases.jsonl` is the authoritative test input and precomputed gold. `cases.schema.json` defines its shape. `rubric.json` defines scoring and handling of unavailable observations. `splits.json` declares the split. `manifest.json` hashes every frozen file other than itself; its digest is reported when freezing. No candidate executions or outputs were inspected in authoring these fixtures. Dataset self-validation only checks schema consistency, allowed evidence, stable row mapping and arithmetic from raw fixture values.

Fixtures are under `fixtures/`. `project.json` is the corpus manifest, `experiments.json` contains independent source tables in its `sources` array, `memories.json` contains memory records, and `sync.json` contains current/archived sources and concrete mutations. The top-level X01 table in `experiments.json` is a compatibility alias; adapters must not import it a second time when consuming `sources`. `ectd-experiments.json` is a convenience view of X02/X03/X04 and must not be imported in addition to `experiments.json`.

Source access models BioDesign's native selected-project filesystem scope. P90, X90 and memories M03/M04 reside in an unselected neighboring project. The dataset does not claim the app implements enterprise user roles or per-row ACLs. `principal` is the local user, not an authorization-role simulation. Symlink/path escape cases must exercise production path checks. Side Chat recommendations must not dispatch Agent Command; an explicitly selected Agent Command case can prepare a plan without claiming that a physical experiment occurred.

Each source row has a stable row ID, source ID, sheet, physical row number, raw values, normalized gold values and evidence ID. The three EctD sources use English, Chinese, and mixed headers. Raw source fields are the adapter input. Normalized values and gold entries are evaluator truth and must never be used to implement or answer a production query. Null values are missing, not zero; failed and pending rows are excluded when completed rows are requested. Native parser limitations must be reported as limitations.

`allowed_tools` contains semantic capabilities, not fabricated production tool names. The adapter records its explicit mapping to real application tools and actual entry points. A live model and grounded final response are required for end-to-end language/claim/action-boundary assertions. Tool-only results are a separate execution mode. Missing capabilities, missing live credentials, missing audits, uninstrumented faults and unobserved final responses are **unknown/unmeasured**, not pass. No keyword router, hand-written canned answer or normalized-fixture answer may replace the actual app.

Sync cases declare `setup.initialSourceVersions`, `setup.sourceStates`, and concrete `setup.mutations`. Numeric fixture versions are labels. A production content hash proves a fixture version only when it matches the exact materialized source bytes. Repeated corpus questions use `setup.turns`. A failure must be injected at the declared real boundary and recorded. A source-read fault with `withholdTextFromSearch` also suppresses text-bearing search snippets for that source; otherwise correct answers could still be grounded through search. Transient map failure occurs once; persistent read/query failure lasts the case. If the adapter cannot inject a condition faithfully, report unmeasured.

Generation sources are frozen for provenance. Do not regenerate or modify these files after any candidate execution. Put run outputs outside this directory. Any later dataset change requires a new version/directory, a new freeze, and a separate baseline.
